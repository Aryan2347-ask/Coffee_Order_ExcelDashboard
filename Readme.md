<h1 align="center">☕ Coffee Sales Dashboard</h1>



Project Overview

This project is an interactive Coffee Sales Dashboard created in Microsoft Excel. The dashboard helps analyze coffee sales performance across different countries, customers, and products using dynamic charts, slicers, pivot tables, and KPI tracking.



The goal of this project is to transform raw coffee order data into meaningful business insights that support decision-making and sales analysis.



Features

* Interactive Excel Dashboard
* Dynamic Pivot Tables \& Pivot Charts
* KPI Tracking for Total Sales
* Country-wise Sales Analysis
* Customer-wise Sales Analysis
* Product Performance Monitoring
* Slicers for Easy Filtering
* Clean and Professional Dashboard Design



Dashboard Insights

* The dashboard provides insights such as:
* Top-performing coffee products
* Best-selling regions/countries
* High-value customers
* Overall revenue trends
* Comparative sales analysis
